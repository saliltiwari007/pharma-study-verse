# Pharma Study Verse — UI Design System

## Experience goal
A clean, professional, fast and friendly pharmacy-learning interface. The site should feel like a focused academic product, not a long marketing page.

## Information architecture
Keep navigation shallow:
- Home
- Learn
- Practice
- EduGames
- Career Path
- Exams
- Dashboard (signed-in)

Use contextual sub-navigation inside each area rather than putting every feature in the global header.

## Page-length rule
Do not create unnecessarily long single pages. Prefer focused screens and progressive disclosure:
- short hero;
- concise feature overview;
- clear primary action;
- compact subject/program cards;
- details in dedicated screens, drawers, accordions or modals when appropriate.

## Content hierarchy
One primary goal per screen. Use clear headings, short descriptions, consistent cards and meaningful empty states. Avoid large walls of text and repeated promotional copy.

## Student-first dashboard
The first view should answer:
1. What should I study now?
2. How am I progressing?
3. Where do I need attention?
4. What can I practice next?
5. What have I achieved?

Show progress, weak topics, upcoming recommendations, recent activity, badges and optional rankings without overwhelming the student.

## Responsive behavior
Mobile is first-class, not a reduced desktop version. Use responsive grids, touch-friendly controls, readable type, sticky but compact navigation and no horizontal overflow.

## Accessibility
Maintain keyboard navigation, visible focus, semantic headings, accessible labels, sufficient contrast, reduced-motion support and feedback that does not rely on colour alone.

## Ads
Ads must be visually separated from educational controls. Never cover active questions, obscure answers, interrupt an active game/assessment or create accidental clicks. Premium prompts must remain secondary to learning.

## Trust UI
For governed academic/career information, expose source/verification metadata unobtrusively (for example, a "Source & verification" expandable panel). Keep the global disclaimer compact and link to the full policy.

## Visual direction
Use restrained academic styling: generous whitespace, clear typography, subtle borders/shadows, consistent radii and a small design token set. Avoid excessive gradients, animations, badges, pop-ups and decorative clutter.

## Feature discipline
If a feature does not improve learning, navigation, assessment quality, career clarity, accessibility, safety or sustainable operation, it should not be added merely to make the page look bigger.
